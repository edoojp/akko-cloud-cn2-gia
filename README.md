## 下单前必须知道的五件事

**流量是双向计的。** 套餐写的 500GB、800GB、1200GB 是上行加下行的总和，不是单向。跑下载、做镜像、挂 PT 的人要按一半算实际可用，500GB 套餐的真实单向额度大约 250GB。

**只支持支付宝。** 公开的付款方式里没有 PayPal 和信用卡，习惯用外卡的人要先解决付款通道。

**服务条款不支持退款。** 公开条款和第三方评测都提到不退款，下单前把机房、配置、计费周期核对清楚。想验证线路，用季付或月付，别直接上年付。

**续费价在结算页确认。** 公开页面没有明确写续费同价，首购价和续费价可能不同。下单时看清账单周期和续费金额，别按首年价做两三年预算。

**现货和开通时间。** 官网不显示实时库存数字，购买页能正常选配置、进结算并付款，就说明当前可下单；某个档位选不了或下架，换档或等补货。开通方式和工作时间以购买页和工单回复为准。

## 常见问题

**CN2 GIA 和 CN2 GT 有什么区别？**
GIA 走独立的轻载路径，晚高峰拥塞概率低；GT 走 163 骨干，和普通流量一起挤。GIA 的价值在晚高峰稳定性，峰值带宽不是重点。

**299 元的入门款够不够用？**
美国线 299 元给 1GB 内存，挂 WordPress、Typecho、探针、轻量代理够用；德国线 299 元只有 512MB，跑 WordPress 要优化，建议上 699 元那档。

**联通用户能用吗？**
公开的第三方路由测试显示圣何塞线路联通回程也走 CN2 GIA（AS4809），移动回程走 CMIN2，但各地联通出口质量有差异。不确定就先买 99 元/季试一季。

**能装 Windows 吗？**
公开套餐页没有标注 Windows 选项，需要 Windows 的读者下单前问客服确认，别默认 KVM 就一定能装。

**优惠码怎么用？**
结算页有优惠码输入框，填进去点验证，能抵扣就说明有效，不能抵扣就按原价。公开渠道没有确认当前有效的长期码，第三方文章里的旧码别当承诺。
